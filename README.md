# Aerovoxel

Projects motion of pixels to a voxel

## Execution

```bash
./scripts/build.sh`
# Usage: ray_voxel <metadata.json> <image_folder> <output_voxel_bin>
`./build/ray_voxel metadata.json images build/voxel_grid.bin
```

## Examples

```bash
./examples/synthetic/run.sh
```

## Development

```bash
./scripts/install.sh
. scripts/activate.s
```
